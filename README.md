# Silkie's Treats

A visual novel set in the Wings of Fire universe written in JavaScript using the [KAPLAY.js](https://github.com/kaplayjs/kaplay) library.

**HEAVILY IN DEVELOPMENT**

Working on ingame assets and the script. The current build is only made out of placeholders.

## How to run:

Select the folder with docker-compose.yml and run the command:
```
docker-compose up --build
```
